

\# HelpDeskPro – IT Help Desk Ticket Management System



HelpDeskPro is a web-based IT Help Desk Ticket Management System built using Python and Django. It helps users create, manage, track, and resolve technical support tickets through a simple dashboard.



\## 🚀 Features



\- User Registration and Login

\- Secure User Authentication

\- Create and Manage Support Tickets

\- View Ticket Details

\- Edit and Delete Tickets

\- Update Ticket Status

\- Ticket Priority Management

\- Search Tickets

\- Dashboard with Ticket Statistics

\- User Profile Management

\- Ticket Comments and History

\- Email Notifications

\- Responsive User Interface

\## ⚙️ Installation and Setup



\### 1. Clone the repository



```bash

git clone https://github.com/karadireddy06-lab/HelpDeskPro.git

```



\### 2. Navigate to the project folder



```bash

cd HelpDeskPro

```



\### 3. Create a virtual environment



```bash

python -m venv venv

```



\### 4. Activate the virtual environment



\*\*Windows CMD:\*\*



```cmd

venv\\Scripts\\activate.bat

```



\### 5. Install Django



```bash

pip install django

```



\### 6. Apply database migrations



```bash

python manage.py migrate

```



\### 7. Create an administrator account (optional)



```bash

python manage.py createsuperuser

```



\### 8. Start the development server



```bash

python manage.py runserver

```



Open your browser:



http://127.0.0.1:8000/



\## 📊 Project Purpose



The main objective of HelpDeskPro is to simplify IT support operations by providing a centralized platform for managing technical issues, tracking ticket progress, and maintaining support history.
